# Praxis

Just a library mod with shared code for my projects.

## **Important Disclaimer**

**This library is under active development and is primarily intended for personal use within my own projects. The API
and functionality are subject to frequent changes without warning. I do not recommend using Praxis in your own mods at
this time, as breaking changes are highly likely.**

I may consider creating a stable, publicly usable version in the future. If this happens, it will be clearly
communicated.

Until then, please refrain from depending on this library for your own projects.
